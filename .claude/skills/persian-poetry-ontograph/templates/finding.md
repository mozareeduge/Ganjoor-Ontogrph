# Finding Template

Create through `ontograph record add --type finding`. A Finding must cite governed operation/source support.

```json
{
  "id": "f-<stable-id>",
  "pressure": "what made the prior account insufficient",
  "operation_or_construction": "<governed-operation-record-id>",
  "observation": "what the persisted operation/source return showed",
  "consequence": "what changes for this inquiry",
  "limits": "scope, mode, ambiguity, coverage, and reopening conditions"
}
```

Do not use a raw dashboard, candidate catalog, or legacy-unframed operation as support for a Finding.
