# Inquiry Proposal Template

The agent prepares this file; the researcher may revise it before `ontograph inquire`. Every semantic entry remains proposal-tier.

```json
[
  {
    "kind": "lexical-anchor",
    "label": "mirror",
    "form": "<Persian form supplied or approved by the researcher>",
    "proposer": "hermes",
    "proposer_type": "agent",
    "rationale": "why this form is worth checking as a candidate route"
  },
  {
    "kind": "non-object-note",
    "label": "scope caution",
    "proposer": "hermes",
    "proposer_type": "agent",
    "rationale": "what should stay visible but not become an object"
  }
]
```

Do not fabricate Persian lexical forms from an English-only hunch. English-only input without supplied Persian vocabulary should produce `needs-vocabulary`.
