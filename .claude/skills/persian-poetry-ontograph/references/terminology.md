# Terminology

Use these terms only for their governed record or operation. They are not interchangeable.

- **ResearchSituation** - the attributed reason the inquiry exists: verbatim hunch, authored situation fields, uncertainty, premature decisions, actor, status, and supersession. New governed work starts here.
- **Seed** - the initiating object or cluster as first conceived. It is provisional and may never become an Object Address.
- **InquiryCatalog** - an append-only proposal envelope containing candidate seed-objects, lexical anchors, authored contrasts, non-object notes, lexical neighbors, support receipts, limitations, and source pointers. It is proposal-tier, not active object state.
- **InquiryReview** - an append-only human decision over catalog candidates: accept, accept-unsupported, reject, defer, revise, or split. review approval != OccurrenceAssessment.
- **Object Address** - provisional persistent identity for something the study returns to after governed promotion. It may split, merge, or remain unsupported.
- **Lexical Anchor** - an approved textual form used to locate candidate passages. Lexical Anchor != object.
- **Anchor Hit** - the deterministic fact that an anchor matched a stable source span. Anchor Hit != object occurrence.
- **CandidateEvidenceRef** - a source pointer proving a candidate form has or lacks raw support. CandidateEvidenceRef != Anchor Hit.
- **Occurrence Assessment** - a human/rule decision that one stable Anchor Hit is accepted, rejected, or ambiguous for one Object Address.
- **Walk** - the guided per-hit assessment route. Evidence cues are shown separately; candidate cue != OccurrenceAssessment.
- **OperationRecord** - persisted provenance for a computation, including situation_id and inquiry_status. A renderer reads it; it does not recompute it.
- **Source manifest** - the stored source-return route for an operation or mapping. It must resolve through `source show`/`source export` before a result supports a Finding.
- **Mapping Object** - a versioned distant-reading construction with source return. Mapping Object != ontology.
- **Trace** - a consequential indication held before it earns formal relation status.
- **Relation-Object** - a relation that needs persistent addressability after human-confirmed prerequisites. co-incidence != Relation-Object.
- **Profile** - a conditioned access route to an object or relation under stated apparatus, source, and limits. Profile != object.
- **Experiment** - a declared change to an encounter condition before execution.
- **Finding** - pressure -> operation -> encounter -> observation -> consequence -> limit, citing governed sources. Finding != artifact.
- **Use-Status** - what a record may currently do.
- **Claim Permission** - how far a proposition may travel.
- **legacy-unframed** - old readable operation history without a ResearchSituation. It cannot support a Finding, Claim, Relation-Object, DescriptiveCatalog, or verified scholarly release.

Non-equivalence audit: Object-Field != world/whole; corpus record != philosophical object; lexical neighbor != object; assessed occurrence != exhaustive object; estimated incidence != exact census; occurrence != object; Profile != Sensual Object; missing information != withdrawal; hidden metadata != Real Quality; empirical chronology != Harmanian Time; geographic location != Harmanian Space; map adjacency != relation evidence by itself; co-incidence != relation; conditional association != causation; relation record != relation proof; AI proposal != evidence; provenance != corroboration; high frequency != wide dispersion; graph centrality != importance; research mediation != corpus recurrence; zero in one field != ontological absence; metaphorical/operational transfer != identity; artistic permission != scholarly claim permission.
