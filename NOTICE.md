## Upstream data

The JSON corpus in this repository (`poets/`, `index/`, `manifest.json`,
`metres.json`, `languages.json`, `API.md`) is exported from
**[Ganjoor](https://ganjoor.net/)** via the
[ganjoor/ganjoor-data](https://github.com/ganjoor/ganjoor-data) repository
and the [GanjoorService](https://github.com/ganjoor/GanjoorService) project.

### License status (verified 2026-08-16)

| Component | Status |
|---|---|
| The **classical poetry texts** themselves | **Public domain** — the poets died centuries ago; the texts are classic works of Persian literature |
| **GanjoorService** (the application that generates/serves the data) | **GPL-3.0** (GitHub API: `spdx_id: GPL-3.0`) — this covers the *software*, not the data |
| **ganjoor-data** (this export repo) | **No license declared** (`license: null` on GitHub) — legally the compilation and any editorial content (structure, metadata, and the AI-generated «هوش مصنوعی:» summaries) are the work of the Ganjoor project |
| The **English semantic summaries** generated by this project's pipeline | **MIT** (licensed with this project's code) |

### What this means in practice

- Using, converting, and redistributing the **poems themselves** is unproblematic —
  they are public-domain classical texts.
- The **compilation and AI summaries** carry no explicit open license. Ganjoor is a
  free, non-profit project; its data is widely redistributed by third parties
  (academic corpora, apps, Kaggle datasets) under an attribution-based practice.
  This project follows the same convention.
- We do **not** claim Ganjoor endorses this work, and we keep the upstream tree
  unmodified. We strip the «هوش مصنوعی:» marker from summaries in our generated
  Markdown but the text remains Ganjoor's content, attributed here.

## This project's additions (MIT)

- `src/` converter and enrichment scripts
- `AGENTS.md`, `README.md`, `queries/`, `.qmd/index.yml`
- The **generated** Markdown corpus (`md/`, released as artifacts):
  - Persian poem files are reformatted public-domain texts with metadata
  - Persian خلاصه mirrors are Ganjoor's AI summaries, reformatted
  - **English semantic summaries** are generated by this project's pipeline
    (LLM-generated from the Persian poem + Persian summary) and are licensed
    MIT along with this project's code

## Usage rules

- Keep this NOTICE and attribution when redistributing.
- Link back to [ganjoor.net](https://ganjoor.net) and
  [ganjoor/ganjoor-data](https://github.com/ganjoor/ganjoor-data).
- Do not claim the Ganjoor project endorses this work.
- The Ganjoor data is provided as-is, "for attribution and compatibility".
- Before any major public launch, it is recommended (and professional) to
  contact the Ganjoor team — a small non-profit — to inform them of the
  derivative work.
