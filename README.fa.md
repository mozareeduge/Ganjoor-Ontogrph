# persian-poetry-ai-agent-plugin

[**English**](README.md) | **فارسی**

**شعر فارسی، آماده برای عامل‌های هوش مصنوعی** — تمام گنجینهٔ شعر فارسی
[گنجور](https://ganjoor.net/) (۲۳۴ شاعر، حدود ۱۳۲٬۵۰۰ شعر) تبدیل‌شده به یک پایگاه
مارک‌داون قابل جستجو، چندزبانه و دوستدار عامل‌های هوش مصنوعی.

این پروژه فورکی از [ganjoor/ganjoor-data](https://github.com/ganjoor/ganjoor-data)
است با یک خط لولهٔ افزوده: **JSON ← مارک‌داون ← ایندکس QMD** (جستجوی معنایی
انگلیسی + جستجوی معنایی فارسی + جستجوی دقیق ابیات، همه به صورت محلی).

## چرا؟

جستجوی معنایی در شعر کلاسیک فارسی سخت است. داده‌های گنجور به صورت JSON خام با
خلاصه‌های فارسی منتشر می‌شود. این پروژه:

1. هر شعر را به یک فایل مارک‌داون تمیز و خودتوصیف تبدیل می‌کند
   (متادیتای YAML + ابیات اعراب‌دار + «متن ساده» + خلاصهٔ فارسی)
2. هر شعر را با **خلاصهٔ معنایی انگلیسی** و کلیدواژه‌ها غنی می‌کند (هر API
   سازگار با OpenAI — قابل تعویض) — تا بازیابی به انگلیسی کار کند و شعر فارسی بماند
3. یک **ایندکس QMD پروژه‌محلی** (`.qmd/index.yml`) با مدل چندزبانه
   (Qwen3-Embedding-0.6B) ارائه می‌دهد — جستجوی معنایی انگلیسی *و* فارسی
4. کاملاً ایزوله است: ایندکس هرگز با ایندکس سراسری QMD دستگاه شما برخورد نمی‌کند

## شروع سریع

پیکره به صورت **آرتifact انتشار گیت‌هاب** عرضه می‌شود (فقط مارک‌داون — ایندکس
برداری را خودتان روی دستگاهتان می‌سازید).

```bash
# پیش‌نیازها: پایتون 3.10+ و QMD 2.5+
npm install -g @tobilu/qmd

# ۱. دریافت کد
git clone https://github.com/erfanbashar1/persian-poetry-ai-agent-plugin.git
cd persian-poetry-ai-agent-plugin

# ۲. دریافت پیکرهٔ مارک‌داون — از آخرین Release (ganjoor-md-v*.tar.gz از صفحهٔ Releases)
tar -xzf ganjoor-md-v0.1.0.tar.gz -C md
#    یا ساخت از دادهٔ داخل مخزن:  python3 src/ganjoor2md.py --input . --output md

# ۳. ساخت ایندکس جستجوی محلی (ایزوله و پروژه‌محلی)
export QMD_TRUST_LOCAL_CONFIG=1
qmd update
qmd embed -c ganjoor-fa      # جستجوی معنایی فارسی (فقط خلاصه‌ها، طبق طراحی)
qmd embed -c ganjoor-en      # جستجوی معنایی انگلیسی (نیازمند خلاصه‌ها؛ از نسخهٔ v0.2)

# ۴. جستجو — دقیق فارسی، معنایی فارسی، معنایی انگلیسی
qmd search "که عشق آسان نمود اول ولی افتاد مشکل ها" -c ganjoor
qmd query "شعرهایی درباره غم و گذر عمر" -c ganjoor-fa
qmd query "poems about the pain of separation at night" -c ganjoor-en

# ۵. در دسترس قرار دادن برای عامل‌ها از طریق MCP
./scripts/mcp-server.sh --daemon   # http://localhost:8191/mcp
```

**ترجیح می‌دهید با `make`؟** [Makefile](Makefile) همان مراحل را شفاف اجرا می‌کند:
`make setup`، `make corpus`، `make index`، `make embed`، `make all`، `make search`،
`make mcp`.

راهنمای کامل گام‌به‌گام و کتابچهٔ عامل‌ها در [AGENTS.md](AGENTS.md) است. عامل‌هایی
که MCP را می‌شناسند می‌توانند [مهارت persian-poetry-mcp](skills/persian-poetry-mcp/SKILL.md)
را برای راهنمای پرس‌وجو بارگذاری کنند.

## معماری

```
دادهٔ JSON گنجور (poets/, index/)             ← بالادست، فقط‌خواندنی
        │  src/ganjoor2md.py (مبدل)
        ▼
md/poets/<slug>/…            → مجموعهٔ "ganjoor"     → جستجوی دقیق فارسی (BM25، بدون بردار)
md/summaries-fa/<slug>/…     → مجموعهٔ "ganjoor-fa"  → جستجوی معنایی فارسی (فقط خلاصه)
md/summaries-en/<slug>/…     → مجموعهٔ "ganjoor-en"  → جستجوی معنایی انگلیسی + BM25
        │  .qmd/index.yml (پروژه‌محلی، همراه مخزن)
        ▼
qmd query/search (ایزوله، Qwen3-Embedding چندزبانه)
```

تقسیم سه‌مجموعه‌ای عمدی است: بردارها **فقط روی خلاصه‌ها** ساخته می‌شوند (هر زبان
خلاصهٔ خودش)، شعرهای کامل در مجموعهٔ واژگانی بدون بردار برای جستجوی دقیق ابیات
می‌مانند، و هر فایل خلاصه یک اشاره‌گر `poem:` به شعر واقعی فارسی دارد.
